# 비공개 테스트 피드백 및 대응

Google Play 비공개 테스트 중 테스터에게 받은 피드백과, 그에 따라 반영한 버전별 대응 기록. 원칙은 **피드백 → 데이터로 원인 진단 → 임시(규칙) + 근본(재학습) 병행**이다.

## 받은 피드백 요약

| # | 피드백 | 유형 | 대응 |
|---|---|---|---|
| F1 | 일부 지역 종결어미가 표준어로 잘 안 바뀜 (경상 `~임다/능교`, 전라 `~당께`, 강원 `~드래` 등) | 정확도 | v1.0.2 후처리 + 변환기 v2 재학습 |
| F2 | 짧게 한두 단어만 말하면 인식이 불안정 | 인식 안정성 | v1.0.3 STT 튜닝 |
| F3 | 어휘 자체가 사투리인 경우(동사·부사 등)를 표준어로 못 옮김 | 정확도 | 변환기 v2 어휘 증강 |
| F4 | 표준어 → 지역 사투리 역방향 번역도 있으면 좋겠다 | 기능 건의 | v2 후보(백로그) |

## 버전별 대응

### v1.0.2 — 후처리 안전망 + 짧은 발화 안정화 (F1·F2)

- **하이브리드 후처리 안전망** — `data/` 전수검색으로 경상 존대 종결어미(`아임다/~임다`)가 학습쌍에 **0건**(커버리지 공백)임을 진단. 모델을 건드리지 않고 변환 출력에서 명백·무맥락 표현만 규칙 보정(오탐 방지 가드 + 유닛테스트 20/20). 재학습 없이 즉시 배포되는 1차 방어선. → [mobile/src/dialectPostfix.js](../mobile/src/dialectPostfix.js)
- **짧은 발화 안정화** — Whisper는 30초 윈도 모델이라 아주 짧은 클립을 무음 패딩하며 환각이 잦다. STT 디코딩에 빔서치(beamSize 3) + temperature 0 + 도메인 프롬프트를 적용하고, 700ms 미만 녹음은 변환하지 않고 다시 요청. 대기 화면에 "짧은 문장으로 또박또박" 안내 추가.

### v1.0.3 — 다운로드·권한 견고화

테스터 초기 설치 경험을 다지는 안정화(직접적 피드백보다는 실사용 관찰 기반).
- **이어받기** — 다운로드 진행 상태를 저장해 앱이 중간에 죽어도 처음부터 다시 받지 않음.
- **모델 버전 매니페스트** — 파일별 태그로 변환기만 증분 갱신(아래 v2 배포에 사용).
- **셀룰러 경고 게이트** — 최초 490MB 다운로드가 필요한데 모바일 데이터면 "데이터로 계속 / Wi‑Fi 대기" 동의를 먼저 받음.

### 변환기 v2 (models-v2) — 합성 증강 재학습 (F1·F3 근본 해결)

후처리(규칙)는 임시방편이라, 근본적으로 **데이터로 학습**시켰다.

**진단** — 학습 데이터를 전수 분석([../training/ending_coverage.md](../training/ending_coverage.md))한 결과, AI Hub 방언 데이터는 지역 라벨이 붙어 있어도 **정작 지역 상징 어미가 거의 표준어에 가깝게** 발화돼 있었다:

| 지역 대표 어미 | 학습쌍 등장 |
|---|---|
| 경상 `임더`·`능교`·`니껴` | 0~1건 |
| 전라 `랑께`·`당께`·`부렀` | 0~1건 |
| 강원 `드래`·`드래요` | 6~7건 |

**증강** — 실제 표준 문장에 지역 어미·어휘 치환을 적용해 `(합성 사투리, 표준어)` 쌍을 생성. 어미 9.6만([../data/augment_endings.py](../data/augment_endings.py)) + 어휘 5만([../data/augment_lexical.py](../data/augment_lexical.py))을 balanced 70만에 섞어 KoBART 재학습(로컬 RTX 3080, 56분).

**검증** (held-out from val):

| 검증 | 기존 모델 | 증강 모델 |
|---|---|---|
| 어미 변형 CER | 1.69% | **0.08%** |
| 어미 변형 정확일치 | 75.2% | **98.0%** |
| 어휘 변형 정확일치 | 80.8% | **90.8%** |

일반 성능 회귀는 미미(변환 CER 1.63→1.74%). int8 `.pte` export 후 PyTorch 대비 **정합성 8/8**([../backend/parity_aug.md](../backend/parity_aug.md)). 새 변환기는 `models-v2`로 호스팅하고, 앱의 버전 매니페스트가 변환기 `.pte`(314MB)만 증분 갱신한다(STT 유지). 검증 상세 [../training/eval_aug.md](../training/eval_aug.md).

## 백로그

- **F4 — 역방향 번역(표준어 → 지역 사투리)**: 기존 쌍의 방향만 뒤집으면 학습 데이터는 확보되나, one-to-many(정방향보다 어려움)·타깃 지역 선택·리밸런싱이 필요한 독립 기능이라 v2로 분리. 상세 [DEVELOPMENT_JOURNEY.md](../DEVELOPMENT_JOURNEY.md) 로드맵 참고.
