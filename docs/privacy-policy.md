# 개인정보처리방침 — 사투리 번역

**시행일: 2026-09-02**

사투리 번역(이하 "본 앱")은 사용자의 개인정보를 소중히 다루며, 수집을 최소화합니다. 본 방침은 본 앱이 어떤 정보를 어떻게 처리하는지 설명합니다.

## 1. 수집·처리하는 정보

본 앱은 **계정을 요구하지 않으며, 이름·이메일·전화번호·위치 등 개인 식별정보를 수집하지 않습니다.**

- **음성 녹음**: 사용자가 녹음 버튼을 눌러 말한 음성만 처리합니다. 이 음성은 사투리를 표준어 텍스트로 변환하기 위한 목적으로만 사용됩니다.
- **마이크 권한**: 음성 녹음을 위해서만 사용하며, 백그라운드에서 녹음하지 않습니다. 권한은 기기 설정에서 언제든 철회할 수 있습니다.

## 2. 음성의 처리와 보관

- 녹음한 음성은 변환 처리를 위해 처리 서버로 전송됩니다.
- 서버는 음성을 **변환에 필요한 순간에만 임시로 사용하고, 처리 직후 즉시 삭제**합니다. 음성 파일이나 변환 결과를 **저장·보관하지 않으며, 데이터베이스에 남기지 않습니다.**
- 변환 결과(텍스트)는 사용자의 기기 화면에만 표시되며, 서버에 저장되지 않습니다.

## 3. 제3자 제공·광고·추적

- 본 앱은 수집한 정보를 **제3자에게 판매·제공하지 않습니다.**
- **광고를 게재하지 않으며, 사용 행태를 추적하는 분석 도구를 사용하지 않습니다.**

## 4. 학습 데이터 출처

본 앱의 음성 인식·변환 모델은 **AI 허브(aihub.or.kr)** 의 한국어 방언 음성 데이터로 학습되었습니다. 이 학습 데이터는 앱 제작 과정에서만 사용되었으며, 사용자의 음성과는 무관합니다. 사용자의 음성은 모델 학습에 사용되지 않습니다.

## 5. 아동의 개인정보

본 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.

## 6. 보안

음성 전송은 암호화된 연결(HTTPS)로 이루어지며, 처리 후 즉시 삭제되어 유출 위험을 최소화합니다.

## 7. 방침의 변경

본 방침이 변경될 경우 본 문서와 앱을 통해 고지합니다. 변경 시 시행일을 갱신합니다.
