개인정보처리방침 — 알아 묵나?

시행일: 2026-09-04

알아 묵나?(이하 “본 앱”)은 사용자의 개인정보를 소중히 다루며, 수집을 최소화합니다. 본 앱은 음성 인식과 표준어 변환을 모두 사용자의 기기 안에서(온디바이스) 처리하며, 사용자의 음성을 외부로 전송하지 않습니다.

1. 수집·처리하는 정보

본 앱은 계정을 요구하지 않으며, 이름·이메일·전화번호·위치 등 개인 식별정보를 수집하지 않습니다.

  • 음성 녹음: 사용자가 녹음 버튼을 눌러 말한 음성만 처리합니다. 사투리를 표준어 텍스트로 변환하기 위한 목적으로만 사용됩니다.
  • 마이크 권한: 음성 녹음을 위해서만 사용하며, 백그라운드에서 녹음하지 않습니다. 권한은 기기 설정에서 언제든 철회할 수 있습니다.

2. 음성의 처리와 보관 (온디바이스)

  • 녹음한 음성은 사용자의 기기 안에서만 처리되며, 어떤 서버로도 전송되지 않습니다.
  • 인식·변환은 기기에 저장된 AI 모델로 기기 내부에서 수행됩니다. 음성 파일은 변환을 위해 앱 내부 저장 영역에 임시로 생성되며, 다른 앱이나 외부에서 접근할 수 없고 기기를 벗어나지 않습니다.
  • 변환 결과(텍스트)는 사용자의 기기 화면에만 표시되며, 어디에도 저장·전송되지 않습니다.

3. 인터넷 사용 (모델 다운로드)

  • 본 앱은 최초 실행 시 1회, 음성 인식·변환에 사용할 AI 모델 파일을 내려받기 위해 인터넷에 연결합니다. 이후에는 인터넷 없이 오프라인으로 동작합니다.
  • 이 다운로드 과정에서 사용자의 음성이나 개인정보는 전송되지 않습니다. 모델 파일을 받아오기만 합니다.
  • 모델 파일은 GitHub의 공개 저장소에서 제공되며, 일반적인 웹사이트 접속과 마찬가지로 파일 제공 서버(GitHub)에는 접속 기록(예: IP 주소)이 남을 수 있습니다. 이는 본 앱이 수집·보관하는 정보가 아닙니다.

4. 제3자 제공·광고·추적

  • 본 앱은 사용자의 정보를 제3자에게 판매·제공하지 않습니다.
  • 광고를 게재하지 않으며, 사용 행태를 추적하는 분석 도구나 크래시 리포팅 도구를 사용하지 않습니다.

5. 학습 데이터 출처

본 앱의 음성 인식·변환 모델은 AI 허브(aihub.or.kr)의 한국어 방언 음성 데이터로 학습되었습니다. 이 학습 데이터는 앱 제작 과정에서만 사용되었으며, 사용자의 음성과는 무관합니다. 사용자의 음성은 모델 학습에 사용되지 않습니다.

6. 아동의 개인정보

본 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.

7. 보안

음성이 기기를 벗어나지 않고 기기 내부에서만 처리되므로, 전송 중 유출이나 서버 저장에 따른 위험이 원천적으로 없습니다. 모델 다운로드는 암호화된 연결(HTTPS)로 이루어집니다.

8. 방침의 변경

본 방침이 변경될 경우 본 페이지와 앱을 통해 고지합니다. 변경 시 시행일을 갱신합니다.
