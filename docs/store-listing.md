# 플레이스토어 등록정보 (초안)

Play Console에 그대로 붙여넣을 수 있는 스토어 리스팅 초안. 자산은 [`docs/store-assets/`](store-assets/).

## 기본 정보
- **앱 이름**: 알아 묵나?
- **카테고리**: 도구 (대안: 교육)
- **태그**: 번역, 사투리, 방언, 표준어, 음성 인식
- **광고**: 없음 · **인앱 구매**: 없음 · **콘텐츠 등급**: 전연령(예상)

## 짧은 설명 (≤80자)
```
충청·강원·전라·경상 사투리를 표준어로. 인터넷 없이 기기 안에서 바로.
```

## 전체 설명 (≤4000자)
```
사투리로 말하면 표준어로 바꿔드려요.

"알아 묵나?"는 충청·강원·전라·경상 사투리 음성을 표준어 문장으로 옮겨주는 번역 앱입니다. 사투리가 익숙하지 않은 분, 지역 어르신과 대화하는 분, 사투리를 배우고 싶은 분께 도움이 됩니다.

■ 온디바이스 — 인터넷 없이, 기기 안에서
모든 음성 인식과 번역이 여러분의 휴대폰 안에서 처리됩니다. 서버로 음성을 보내지 않으니 인터넷 없이도 동작하고, 데이터 요금 걱정도 없습니다.

■ 프라이버시 — 음성이 기기를 벗어나지 않아요
녹음한 음성은 서버나 클라우드에 저장되지 않습니다. 오직 이 기기 안에서만 처리되고, 로그인이나 계정도 필요 없습니다.

■ 네 지역 사투리
충청·강원·전라·경상 사투리를 지원합니다.

■ 이렇게 쓰세요
1. 마이크 버튼을 누르고 사투리로 말합니다
2. 버튼을 다시 눌러 멈춥니다
3. 인식된 사투리와 표준어 결과가 화면에 나타납니다

■ 처음 실행 시
앱을 처음 켜면 음성 인식·번역에 필요한 모델을 한 번 내려받습니다(약 490MB, Wi‑Fi 권장). 이후에는 인터넷 없이 오프라인으로 사용할 수 있습니다.

■ 데이터 출처
음성 인식·번역 모델은 AI 허브(aihub.or.kr)의 한국어 방언 음성 데이터로 학습했습니다. 사용자의 음성은 모델 학습에 사용되지 않습니다.
```

## Data Safety 양식 요약 (콘솔 입력용)
- 데이터 수집: **없음** (음성은 온디바이스 처리, 저장·전송 안 함)
- 데이터 공유: **없음**
- 마이크(RECORD_AUDIO): 음성 인식 목적, 기기 내 처리, 저장 안 함
- 인터넷(INTERNET): 최초 1회 모델 다운로드용, 개인정보 전송 없음
- 암호화: 다운로드는 HTTPS · 계정/로그인 없음
